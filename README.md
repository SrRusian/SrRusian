### Featured project

**[GAGA Platform](https://github.com/SrRusian/gaga-platform)** — real-time fleet monitoring for mining operations.

GPS/RTK telemetry with safety rules on top: geofences, speed limits, collision risk, proximity alerts and incident reporting. Modular services behind a single gateway, project-level data isolation across API, database and WebSockets, single-session JWT auth revalidated on every request, an offline-capable Android app for in-vehicle tablets, and Dockerized deployment with automatic HTTPS, scheduled backups and CI.
